# Adquisiciones pendientes

No se incorporó un artefacto primario con hash verificable del Acuerdo 013 de 1998 ni del MDT-2017-0068/Acuerdo 068. Se conservan las referencias oficiales del Registro Oficial No. 14 (14/06/2017) y del Ministerio como OFFICIAL_REFERENCE_ONLY. La relación 013 → 068 queda AMENDMENT pendiente.

También faltan fuente SUT vigente para capacitación, fuente técnica oficial psicosocial y unidades del Anexo 3 para otros dominios. Hasta resolverlas no se derivan criterios ejecutables. RETIE, REBT y NFPA 70E no se convierten en ley ecuatoriana; RTQ queda limitado a Quito.
