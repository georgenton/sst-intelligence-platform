individual es deliberada: el texto localizado no basta para expresar actor, alcance,
condición y vigencia como una obligación ejecutable con provenance verdadera.

el trabajo del corpus, pero no crea reviewer, firma ni aprobación individual. No se inventan
artículos, umbrales, actores ni aprobaciones para cerrar el estado.
