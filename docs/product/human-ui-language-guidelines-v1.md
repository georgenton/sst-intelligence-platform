# Human UI language guidelines V1

Primary UI uses Spanish product language. Internal role enums, entitlement keys, rule/fact keys,
operators, method provider keys and raw JSON belong only in an intentional “Detalles técnicos”
disclosure. The shared lexicon is `apps/web/lib/human-lexicon.ts`.

Use “metodología utilizada” for the generic concept. “Matriz demostrativa 5×5” is allowed only as
that method's proper human name. Regulation explains which obligations/context may apply;
methodology explains how risk is evaluated; expert guidance helps a professional apply it. Never
present these as equivalent.

Use “Añadir evidencia” and “Enlace”; describe declared evidence as unverified. Use “Solicitar cambio
de plan” and explain that a request does not change the plan automatically. Solution Finder provides
commercial/operational module recommendations, not legal applicability, method selection or
compliance certification.
