# ¿Qué es SST Intelligence?

SST Intelligence es un espacio para organizar la gestión de Seguridad y Salud en el Trabajo. Ayuda a pasar de una evaluación de contexto a un plan revisable y a un trabajo operativo con trazabilidad: inspección, hallazgo, acción, evidencia, capacitación, EPP, incidentes y observaciones. Los resultados determinísticos se muestran con su contexto; la decisión profesional sigue siendo humana.

Esta entrega prepara una revisión visual y funcional de lo que existe hoy. No construye un dominio nuevo, no publica una regla normativa y no cierra una aceptación profesional.

## Límites y hallazgos abiertos

- La cuenta sintética activa la demostración conceptual hasta la fecha que muestra la interfaz. No se debe presentar como producción.
- El API de staging devolvió `404` para las rutas de programa ocupacional y psicosocial en esta ejecución, aunque el código y la UI contienen las superficies. Esto es un bloqueo de entorno que impide afirmar el recorrido remoto completo de B3A.
- El endpoint legado `POST /solution-finder/sessions/:id/complete` devolvió `500` en staging. La Evaluación SST canónica sí finalizó y es el flujo utilizado para esta revisión. No se corrigió aquí porque esta PR organiza el entorno y documenta; el bug requiere una corrección focal aparte.
- El contador superior del centro de comando muestra cuatro centros porque incluye dos centros demo históricos desactivados. La topología activa del fixture tiene dos centros; la diferencia queda visible para discusión.
- Regulatorio conserva `RuleDrafts=5`, `RuleVersions=0`. SISAT sigue `BLOCKED_EXTERNAL_SOURCE` con unidades cero. No se inventaron fuentes ni aprobaciones.
