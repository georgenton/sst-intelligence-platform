# Expert Guidance Layer V1

Expert guidance is versioned contextual support linked to one exact method version. It is neither a
methodology source, legal source, score provider nor expert approval.

`ANITA_GUIDANCE_GTC45_V1@1.0.0` is available in the GTC45 runtime as a CANDIDATE with review and
official UI verification PENDING. It asks about source conditions, medium conditions,
person-related context without blame/diagnosis, control effectiveness, event history and recurring
failures. Every help definition declares `affectsCanonicalScore=false`.

When displayed/used, the finding stores guidance UUID and manifest snapshot with the assessment.
Changing published guidance requires a new version. Guidance responses can support the human
rationale but cannot assign ND/NE/NC, calculate NP/NR, choose acceptability or claim root cause.

No explicit Anita answer or approval was supplied in a verifiable transcript, so all open questions
remain unanswered and `OFFICIAL_SUT_METHOD_OPTIONS=PENDING`.
