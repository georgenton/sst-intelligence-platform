# Workforce Safety V2 — synthetic demonstration

Use only a synthetic demo Organization. Never enter a real worker, incident narrative, medical
detail, investigation, credential or evidence binary.

1. Create/open Position **Técnico de mantenimiento eléctrico**.
2. Register synthetic electrical, arc-flash, projection and auxiliary mechanical risk contexts.
3. Open EPP and inspect deterministic candidates and the decision-boundary notice.
4. Select an item professionally and record the internal Position requirement.
5. Create synthetic Worker **Pedro Técnico Demo** with Work Center, Area and Position.
6. Assign the Position EPP requirement to Pedro; confirm no Membership or seat was created.
7. Record an EPP issue and delivery acknowledgement.
8. Record an unserviceable condition, choose damage as replacement reason and preserve the old issue.
9. Explicitly add the Worker to a synthetic Incident and link that Incident to the damaged original
   issue; the replacement only points back through `replacesIssueId`.
10. Confirm no Incident or Worker involvement was auto-created.
11. Create an Accident/Incident with a bounded event location and internal attention priority.
12. Report it, start Ishikawa, record contributing factors/evidence and a professional summary.
13. Create or reuse an operational Action; its lifecycle and evidence remain canonical.
14. Create an independent Safety Observation and add a bounded evidence note.
15. Confirm the Observation did not create a Finding or Incident.
16. Link the existing Action explicitly, move to action required and later resolve with a note.
17. Select an existing Plan Operativo item as the canonical source of a Training Need.
18. Add Position and Worker audiences, create a linked Session, register attendance and completion,
    then demonstrate renewal history.
19. Open the printable Training Plan and review manual signature placeholders.
20. Return to Work Queue and confirm only actionable canonical items remain.

The exercise demonstrates reviewed deterministic assistance, not legal compliance, certification,
root cause, medical judgment or an AI decision. EPP/Worker/Incident/Observation/Training data never
leaves the local provider boundary.
