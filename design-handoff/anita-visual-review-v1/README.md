# Entrega visual de Anita V1

Este paquete contiene únicamente capturas de una sesión sintética de staging y `manifest.json`.

- 26 capturas desktop y 4 mobile (`390px`), 30 en total.
- El preview usado fue un deployment de staging protegido por Vercel; el acceso temporal no se incluye aquí.
- Las capturas no contienen contraseñas, tokens, cookies ni `storageState`.
- Las imágenes muestran datos sintéticos de **SST Intelligence — Revisión Anita**.
- El paquete se capturó después de que `demo:anita:verify` pasara en staging; además de HTTP 200, las rutas principales tienen assertions de contenido.
- Salud ocupacional y psicosocial se muestran con fixture sintética aggregate-only. Una ruta con HTTP 200 no sustituye la validación profesional: las decisiones permanecen en `docs/product/anita-visual-review-v1/validation-checklist.md`.
